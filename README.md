## Como executar:
1. Certifique-se de ter o node.js instalado em sua máquina.
2. clone este repositório através do comando:
   ```bash
   git clone git@github.com:samuelfranklin/mb_chalange.git
   ````
3. Navegue até o diretório do projeto: 
   ```bash
   cd mb_chalange
   ```
